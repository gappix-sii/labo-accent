# Labo d'accent
Fiche projet : PROJET.md (quoi et pourquoi) · Plan : PLAN.md (où on en est)

## Commandes
- Lancer : `npm start` (puis ouvrir http://localhost:8000) — à confirmer en phase 1, tâche 2
- Tests : `npm test`

## Règles de travail
- Lire PLAN.md avant toute tâche ; une tâche à la fois.
- Ne cocher une case qu'une fois son critère vérifié (test ou commande qui passe).
- Ne pas changer une décision de la fiche projet sans en discuter ; si elle change, mettre à jour la section Décisions.
- L'utilisateur débute en code : expliquer chaque terme technique, et dire précisément quoi tester dans l'appli.
- Dépôt public : aucun push sans accord ; ne jamais committer `conversation-anglais.md` ni une clé.
- Ancien code dans `ancien/` : on y recycle, on n'y modifie rien.
